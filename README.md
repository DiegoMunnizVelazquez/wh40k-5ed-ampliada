# wh40k-5ed-nuevas-unidades

Repositorio para crear unidades nuevas jugables en Warhammer 40K 5ª edición (NewRecruit / BattleScribe) y para modificar o actualizar los perfiles ya existentes en el repositorio base [wh40k-5ed](https://github.com/DiegoMunnizVelazquez/wh40k-5ed).

## Estructura

| Carpeta | Contenido |
|---|---|
| `unidades/` | Catálogos (`.cat`) y fichas de las unidades nuevas o modificadas. |
| `datos/` | Bases de datos de perfiles, armas y reglas para analizar y comparar. |
| `analisis/` | Informes de comparación entre unidades nuevas y las existentes. |

El sistema de juego (`.gst`) y los catálogos base viven en el repositorio hermano `wh40k-5ed`.
